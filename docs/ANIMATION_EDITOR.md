# 动画编排 · 0.2

本阶段完成了「编辑关键帧 → 编排组件 → 试播 / 滚动预览 → 保存 → 恢复 / 导入」流程。所有参数使用结构化 TypeScript 类型，不保存脚本或 HTML。

## 开始编排

1. 选中画布组件，点击底部「加入选中组件」。组件会接在已有共享轨道的末尾，开始时间最高 30 秒。
2. 打开右侧「动画」。选择预设快速设置首尾，或自行编辑关键帧。预设会替换当前组件的帧列表，可撤销。
3. 点击「添加关键帧」。系统在最大间隔的中点插入一帧；选择帧后调整位移、缩放、旋转、透明度与进入该帧的曲线。
4. 通过轨道拖动、左右方向键（每次 0.1 秒）或右侧开始时间安排重叠 / 顺序。时长在右侧数值面板修改。
5. 点击「试播」。播放、暂停，或拖动进度检查任意时刻；完成后再播放会从头开始。
6. 切换「滚动体验」核对真实触发。所有动画数据通过自动保存、手动保存、JSON 导出一并保留。

轨道图上的菱形是帧位置标记；选择和调整关键帧使用右侧列表。设计画布始终保持静态，因此不会因为起始透明度而无法选择组件。

## 两种播放方式

**独立滚动触发**：每个组件根据自身位置启动，拥有自己的触发线和 scrub。关键帧位置是该组件自身时长的比例。

**共享时间轴**：多个组件共用一个触发器与时间坐标。底部「共享滚动触发设置」选择触发元素、触发线、滚动距离与是否跟随滚动。可选择任意节点作为触发目标；删除目标或祖先后自动恢复为整个页面。

开启共享 scrub 时，0 秒到整条时间轴结束映射到指定的滚动距离；开始时间和时长决定相对节奏，动画不会按墙上时钟计时。关闭 scrub 时触发后按秒播放，向上离开触发线时反向播放。短页面的实际滚动距离受页面底部限制。完全没有滚动空间时，scrub 直接展示完成状态，普通触发按时长播放。

时间轴试播只播放共享轨道，独立触发组件保持静态。滚动体验播放两种模式。系统开启 reduced motion 时，两种预览都恢复静态设计，试播播放 / 进度控件停用。

## 数据与边界

- schema version 2。兼容 v1 本地草稿与 JSON；旧的 x/y/scale/rotation/opacity 转成 0% 首帧，原设计状态转成 100% 尾帧，旧时长、触发线与 scrub 不丢失。
- 每个组件 2–12 帧，0% 与 100% 不可删除或移动，中间帧位置必须严格递增。完整状态明确保存，后续帧不会隐式继承缺失参数。
- 开始时间 0–30s，时长 0.1–10s；曲线为线性、缓出、缓入缓出、轻微回弹。每段使用目标帧的曲线，首帧曲线不参与计算。
- 复制组件会重建组件和关键帧 ID，保留编排参数。编辑、加入轨道、移动轨道、删帧与触发设置均在撤销历史中。
- 父容器和子组件都运行动画时，位移会自然叠加；精确编排时应有意识地选择动画目标。
- 当前只有一条共享时间轴，不包含 pin、多场景、循环、贝塞尔曲线编辑、轨道伸缩手柄、菱形拖动或线上发布。
