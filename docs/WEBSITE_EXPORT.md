# 0.7 · 网站 ZIP 导出

## 使用

1. 编辑作品，检查桌面、平板和手机预览。
2. 点击顶部下载图标，或从页面菜单打开「导出网站 ZIP」。手机从页面菜单打开。
3. 处理标为「需处理」的问题，查看建议与说明。结构检查不是网络可用性或无障碍认证；建议项不阻止导出。
4. 点击「下载网站 ZIP」，可在处理中取消。成功提示表示文件已生成，实际保存位置由浏览器决定。
5. 解压后打开 index.html，或将整个目录上传到 GitHub Pages 等静态托管；不要只上传 HTML。

导出捕获当前画布快照，包含尚未自动保存的修改。它不会自动发布作品或改变当前作品；JSON 工程导入 / 导出继续保留。

## 文件

```text
index.html                  # 真实正文及安全转义的动画数据
styles.css                  # 页面基础样式和三个断点的样式
runtime.js                  # 从 TypeScript 构建的 GSAP / ScrollTrigger 运行文件
images/landscape.svg         # 项目自带的图片占位素材
media/                      # 本地及成功打包的外部图片
project.json                # 可重新导入编辑器的完整原始工程
THIRD_PARTY_NOTICES.txt      # GSAP 版权声明、许可地址和 fflate 许可
README.txt                  # 简短使用说明
```

没有在线字体、CDN 或编辑器服务依赖。浏览器须启用 JavaScript 才能运行动画；禁用时正文仍可阅读。导出使用系统字体回退，字形和字宽可能与加载了 Google Fonts 的编辑器略有差异；同一字体环境下共用相同样式计算。自带运行文件约 123KB（具体以构建产物为准）。

所有资源路径相对当前 HTML，支持 file://、域名根路径和任意静态子目录。内部锚点变成普通 HTML id / href，不依赖编辑器 Hash 路由。外部按钮仍可打开外部网站，这是导航而非页面运行依赖。

## 图片

作品内图片从 Base64 解码成独立文件，源工程备份仍保留图片，方便重新编辑。项目自带 SVG 随包附带。

外部图片会通过浏览器 fetch 读取，采用 CORS 并省略凭据；不代理请求、不绕过服务端跨域策略。支持可解码的 PNG、JPEG、WebP，使用与素材库相同的尺寸和压缩限制。外部 SVG / GIF 等格式需先转换为支持的静态图片。读取失败、超限或解码失败会停止导出并提示改用本地素材，不生成声称完整的缺图 ZIP。

每个资源读取超时 15 秒，流式读取超过 8MB 即取消；最多 20 个不同外部图片地址，图片资源合计限制约 24MB，最终未压缩文件内容合计不超过 40MB。相同外部地址只打包一次。ZIP 使用存储模式，避免对已压缩图片反复压缩导致卡顿。取消会中断网络请求，未成功完成不启动下载。

project.json 保留原工程：原本使用外部 URL 的图片在重新导入后仍使用原 URL；独立网站则使用已打包的本地图片。

## 检查与一致性

导出器与 Vue 画布共用 nodeStyle / imageStyle、基础页面 CSS，以及 mountPageAnimations。断点仍是 ≤600px 手机、≤900px 平板、其余桌面。独立动画与共享时间轴保持关键帧、开始时间、触发位置、距离与 scrub。减弱动态效果时保留内容可见。

HTML 文本、属性及内嵌 JSON 分别安全转义，CSS 仅由已校验的数值 / 枚举生成；不执行用户 HTML 或 JavaScript。首屏正文直接在 HTML 中，不等待 Vue 或编辑器初始化。

构建先生成独立运行文件和许可说明到 public/export-runtime（Git 忽略），再构建编辑器；CI 也运行同样流程。1.0 起 `npm run dev` 启动前也会自动生成，修改动画运行逻辑后重新启动或运行 `npm run build:runtime`。源码始终为 TypeScript，runtime.js 是构建产物。
