# Scroll Studio 1.0.0

2026-10-21。1.0 定义为本地优先的单页网页与滚动动画创作工具。Vue 3、TypeScript strict、Pinia、Vue Router 和 GSAP / ScrollTrigger 保持不变，编辑器仍由 GitHub Pages 自动部署。

## 可以完成的工作

从五个内容模板或空白画布开始，添加及嵌套组件、调整顺序和三个尺寸的样式，上传本地图片，配置关键帧、独立动画与共享时间轴，在独立视口里预览。作品自动保存在当前浏览器的 IndexedDB，可导出、导入 JSON 工程，也可下载包含 HTML、样式、图片、动画和工程备份的 ZIP 网站。

ZIP 解压后可直接打开，或整体上传静态托管；不会自动替用户发布。外部图片须允许跨域读取，不可读取时提示上传本地素材；导出采用系统字体回退。

## 本轮修复

- 导出节点选择器的优先级不足，导致基础样式覆盖字重、行高和图片高度；现在与画布配置一致。
- 手机最小高度设置为 0 时未覆盖桌面导出规则；现在明确生成零值，三个断点都检查实际计算样式。
- 容器复制后内部链接仍指向原件；现在重建节点和关键帧 ID，并改写复制子树内的锚点，外部目标保持原样。
- WebKit 原生拖拽可能清空自定义 MIME；新增带标记的文本回退，外部普通文本不会被当成组件。
- 新建、重命名、删除和预览使用原生模态窗口，补齐焦点循环与返回焦点；预览 iframe 提供 Tab 边界和 Esc 通道。
- 弹窗内快捷键可能触发画布操作，WebKit 原生撤销还可能作用于后台输入框；现在隔离这些操作，同时保留弹窗输入框的原生编辑。
- ResizeObserver 回调内直接更新布局可能出现循环通知；改为在下一动画帧更新，并在卸载时取消。
- 图片和链接检查统一使用规范化 URL，拒绝浏览器会移除的内嵌控制字符，减少预览与导出差异。
- 页面进入后台时尝试保存并写恢复日志；这不能保证操作系统强制终止时一定完成，JSON 仍是跨设备和清理数据前的备份方式。
- 新克隆仓库启动开发服务前自动生成网站导出运行文件；Node 最低版本明确为 22.18，页面版本统一读取 package.json。

## 升级与回滚

用户继续访问原网址，无需手动迁移。1.0 没有改变 schema v3 或数据库版本，继续兼容 v1 / v2 JSON；保持原来的存储键和 IndexedDB 数据。建议升级前导出重要作品的 JSON。换域名、设备或浏览器时须自行导入备份，不会自动同步。

维护者以正常提交和推送 main 发布。发生问题时 revert 有问题的提交，再由同一工作流检查、部署；不要清空用户存储或强推历史。`v1.0.0` 标签用于定位已经验收的代码，后续修复使用新版本。

## 验收

```sh
npm ci
npm test
npm run build:pages
npx playwright install chromium firefox webkit
npm run test:smoke:all
```

单元测试为 7 个文件、118 项。浏览器检查覆盖新建、真实拖拽、编辑、撤销重做、保存刷新、v3 带图备份往返、存储失败导航保护、模板、导出取消和失败、真实 ZIP 解压、file:// 与静态子目录、禁用 JavaScript 仍可阅读、动画、减弱动态效果切换、后台保存、模态键盘操作及导出响应式重置。迁移 v1 / v2 和并发写入冲突另由自动测试覆盖。

本地使用 Windows 上 Playwright 的 Chromium / Firefox / WebKit；CI 使用 Ubuntu 上相同的三种引擎。WebKit 检查不等同于实机 Safari 或 iOS 认证；390px 视口不等同于真实手机。没有做完整无障碍认证、所有浏览器版本矩阵或长期压力测试。具体运行结果以 [Actions](https://github.com/LiuYonghao-04/Scroll-Studio/actions) 和 [验收记录](VERIFICATION.md) 为准。

## 产品与许可边界

没有账号、后端、云端存储、订阅、支付、协作、多页面站点或服务器端表单。手机支持点击添加与排序，不承诺原生触摸拖拽。单作品最多 500 个组件、13 层、20 张本地图片及约 8MB 本地图片；工程总量不超过 16MB，历史最多 60 步且有内存估算限制。
