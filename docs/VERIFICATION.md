## 验证中发现并修复的问题

1. TypeScript 7 与当前 vue-tsc 入口不兼容：锁定 TypeScript 5.9 系列。
2. 首页 GSAP 传入 Vue ref 而不是 DOM 元素：修正 scope，消除目标未找到警告。
3. 页面末尾元素的动画触发线可能不可达：使用 ScrollTrigger clamp 边界。
4. 默认锚点链接与 Hash Router 冲突：在预览中处理锚点，不跳出预览页面。
5. 编辑器插入区域影响 flex 间距：改为绝对定位命中区域，避免改变实际内容布局。
6. 导入失败导致后续自动保存停用：将恢复保护和普通错误分离，所有后台保存统一使用受保护的 autosave。
7. 超过节点上限的复制会提前改变选区：仅在事务成功后选中新节点。
8. 浏览器可能把 `/\\host` 规范化成协议相对 URL：补充路径过滤和回归测试。
9. 没有滚动空间的共享 scrub 轨道停在透明起点：刷新触发器时按可用滚动空间完成 scrub，普通触发轨道按秒播放。
10. 图片 load 会重建动画、打断试播：改为只 refresh 触发位置，保留当前 timeline 和进度。
