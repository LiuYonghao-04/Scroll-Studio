# 0.6 · 响应式、素材与预设

## 三个样式断点

桌面为基础样式，平板继承桌面，手机先继承平板再应用手机覆盖。画布工具栏和右侧属性的断点按钮联动。编辑器的显示缩放不改变真实设计宽度：1120 / 768 / 390 px。

预览通过自身页面宽度选择断点：≤600px 手机、601–900px 平板、>900px 桌面。iframe ResizeObserver 监听实际宽度，选择手机预览时不依赖父页面宽度。

修改颜色、排版、尺寸或布局只写入当前断点。右侧显示覆盖数量，「重置此断点，恢复继承」清除当前覆盖；手机重置后仍可继承平板覆盖。修改和重置均可撤销。文字、图片、组件顺序、链接及动画跨尺寸共享。

新建与旧版迁移默认给标题设置手机字号、容器设置手机纵向布局与较小内边距；这些是可编辑的数据，不再通过 CSS 强行盖掉手机样式。可以修改或重置默认覆盖。

## 尺寸和布局

- 宽度：0 自动，或 px / %；更换单位时重置为自动，避免继承的非法百分比。
- 最大宽度：0 不限制，否则限制为指定像素且不超过父容器。
- 高度：0 自适应；最小高度：0 不额外限制。固定高度可能造成文本溢出，请检查不同尺寸。
- 容器支持横向 / 纵向、主轴分布及换行；自动宽度的横向子元素等分空间，显式宽度按配置布局。
- 边框宽度 0–20px，实线 / 虚线 / 点线；字重、行高、图片 cover / contain 均支持断点覆盖。

## 本地图片素材

在左侧「素材」上传图片。选中图片组件后点击「使用」替换图片；未选中图片组件时，会新增根层图片。右侧「选择或上传本地图片」可打开素材面板。素材名称与图片 alt 文案独立。

支持 PNG、JPEG、WebP；不接受 SVG 和动图。浏览器解码真实图片后，最长边缩到 1920px，编码为 WebP（不支持时浏览器可能回退 PNG），保留透明度。原图 ≤8MB、≤8192px 单边、≤2400 万像素；处理后单图 ≤2MB，每个作品最多 20 张，总图片字节 ≤8MB。错误文件、超限或解码失败给出提示，不会污染文档。

素材可重命名；已使用素材显示引用次数并禁止直接删除，先替换图片或删除组件，再移除未使用素材。上传、重命名、使用和删除均进入撤销历史。异步处理期间切换作品 / 离开素材面板，不会把处理结果写入另一件作品。

图片内嵌到文档 assets，随作品写入 IndexedDB，包含在 JSON 导出 / 导入、作品复制和预览消息中。节点通过素材 ID 引用，渲染时解析；备份不依赖临时 blob URL 或外部图片服务器。素材按作品隔离，不会上传云端。

## 区块与动画预设

区块包括首屏介绍、三列特性、图文介绍、行动邀请，点击追加到页面末尾，也可拖到根层或容器插入位置。每次创建独立组件树和 UUID，可以拆开修改、删除或整体撤销；不导入 HTML 字符串。

动画包括向上浮现、柔和淡入、旋入、侧向滑入、缩放展开、视差穿行。应用会启用动画并替换关键帧，可撤销；保留播放模式、轨道开始时间、时长、触发线和 scrub。视差可结合「跟随滚动进度」使用。动画仅在预览执行，画布保持静态可编辑。

## schema 与备份

schema 为 v3；旧 v1 动画先转换为关键帧，再与 v2 一起升级到带 responsive / assets / 完整样式的 v3。读取迁移不修改原输入或原 localStorage 备份，编辑后保存才更新作品。重复解析不会重建已有节点和关键帧 ID。

JSON 备份最大 16MB，包含图片；仍保留 500 组件和 13 层嵌套限制。导入检查素材 MIME / 文件头 / Base64 字节数、重复素材 ID、悬空引用、样式键白名单、断点继承后的值和容量；失败不修改作品。旧版本编辑器不能读取 v3，请使用最新站点导入。

撤销历史最多 60 步，按文档大小提前裁剪，以免图片导致大量内存占用；保留至少一个快照。作品复制保留作品内图片引用，副本素材元数据修改不会改变原作品。图片较多时关闭前日志可能超出 localStorage 容量，此时使用浏览器离开提示；普通保存以 IndexedDB 为准。重要作品请主动保存并定期导出 JSON。

0.7 才提供独立静态网站 ZIP 导出；0.6 的 JSON 是可恢复的编辑工程，不能直接当作网页部署。
