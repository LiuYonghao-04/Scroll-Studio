# 作品库 · 0.4

在首页进入工作室，或打开 `/#/projects`。每件作品有独立的 `/#/editor/:projectId` 地址。旧入口 `/#/editor` 打开最近作品，无作品时创建初始画布。

## 创作与管理

- 新建：选择空白画布、个人作品集、产品介绍、滚动叙事。模板生成真实的组件树和动画，可以继续拖动组件、修改内容与编排动画。
- 列表：显示作品名称、最后修改时间、布局缩略图；可搜索名称和刷新列表。缩略图是由标题、背景和布局线索生成的 SVG 示意图，未实现像素截图。
- 复制：生成独立作品，节点与帧 ID 重新创建，内部锚点 / 共享时间轴引用一并修正；修改副本不会改变原件。
- 重命名：在列表或编辑器页面菜单修改名称。
- 删除：先确认再删除；不可撤销，重要作品请先导出。
- 返回列表：编辑器页面菜单 →「我的作品」。新建作品会保留当前作品，不替换原记录。
- 导入 / 导出：列表导入 JSON 会新建一件独立作品，名称重复也不会覆盖原件；编辑器内导入替换当前作品内容，可撤销。单个 JSON 限 2MB。

## 保存与恢复

作品保存在当前浏览器和当前域名的 IndexedDB 中。900ms 自动保存、手动保存，以及切换作品 / 返回列表前的保存都会等待数据库事务完成。写入失败时提示错误，阻止带着未保存修改切换。刷新会恢复文档；刷新或切换作品后不恢复原撤销栈。

关闭页面时同步留下小型恢复日志，防止最后一次输入尚未写入数据库。下次打开，若记录版本匹配则恢复；版本不匹配或日志损坏时保留原数据、暂停自动覆盖，并可下载恢复备份。先导出或下载备份，再刷新重新读取，或手动保存当前画布 / 导入备份继续编辑。

多标签页修改同一作品会检测过期 revision，拒绝旧写入。此功能用于防止静默覆盖，不是多人协作或自动冲突合并。建议同一作品一次在一个标签页编辑。

## 旧版本升级

第一次打开时迁移 0.1–0.3 的旧单页草稿。先验证并转换为 schema v2，再将作品和迁移标记一起提交；旧 localStorage 内容保留。重复打开不会重复迁移；迁移失败可以重试。旧数据损坏时仍可另建新作品或导入有效备份。

文档 JSON 继续使用 schema v2，兼容旧 v1 导入。作品库记录的 ID 独立于文档 JSON ID，导入不会把其他记录覆盖。

## 当前边界

每件作品仍是一张单页。尚无同一作品的多页面路由、云端账户 / 同步、图片文件库、独立断点属性或线上发布。清理浏览器数据、切换浏览器 / 域名会影响本地作品可见性；建议定期导出 JSON。

如果浏览器不支持 IndexedDB 或数据库暂时被阻止，界面会显示错误与刷新入口，不会假装创建 / 保存成功。原数据保留在浏览器中。验证记录见 [VERIFICATION](VERIFICATION.md)。
